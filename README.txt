Nutrient Calculator PWA - v5

Nutrient Calculator PWA v4

Install:
1. Host this folder on GitHub Pages, Netlify, or any HTTPS static host.
2. Open the site in Android Chrome.
3. Tap the Chrome menu and choose Install app / Add to Home screen.

v4 changes:
- Prettier glass/dark UI.
- Calculator, saved amounts, and settings tabs.
- Slider from 0 to 200% with gradient fill and animated result cards.
- Presets: 25%, 50%, 75%, 100%, 150%.
- Save current water volume + nutrient percentage as local presets.
- Apply/delete saved presets.

Default recipe at 100% per 1 L:
- Masterblend 4-18-38: 0.53 g
- Calcium nitrate: 0.53 g
- Magnesium sulfate: 0.265 g

Mix order:
1. Masterblend
2. Magnesium sulfate
3. Calcium nitrate

Acid dosing remains calibration-based because real pH depends on tap water alkalinity.


V5 update: Added a peroxide calculator tab for 3% hydrogen peroxide dosing. Includes gentle/seedling, maintenance, cleaning-with-plants, upper plant-limit, and empty-system rinse presets. Plant-present values are conservative; avoid routine high dosing and flush after empty-system cleaning.
